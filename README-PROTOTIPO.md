# Spirit Gate

O ponto de entrada do projeto agora é o cliente RPG desktop. Abra `rodar-prototipo.cmd`; o alias `jogar-rpg-offline.cmd` permanece disponível. Ambos compilam fontes alteradas e abrem o mesmo launcher, sem Maven ou rede.

Consulte [README-RPG.md](README-RPG.md) para instalação, execução, ferramentas de mapas e geração do pacote Windows. As regras vigentes estão em [Raças e domínios](docs/SISTEMA-DE-RACAS-E-DOMINIOS.md) e no [PDF de design](docs/Spirit_Gate_Racas_e_Dominios.pdf).

A arena e os relatórios históricos continuam como referências e testes técnicos, sem definir a criação atual de personagens. Guardian e Mystic são modelos do protótipo anterior. O experimento web foi descontinuado como caminho do produto; os relatórios HTML de revisão de sprites continuam úteis à produção de arte.
