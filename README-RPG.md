# Spirit Gate RPG offline

Abra jogar-rpg-offline.cmd. A distribuicao Windows tem Java integrado; nao exige Maven, banco, conta ou servidor.

Campanha inicial: crie Guardian ou Mystic, converse com a Ancia, aceite missoes, explore vila/bosque/santuario, obtenha loot, evolua, equipe itens e derrote o chefe. I abre inventario, J diario, M mapa; atalhos completos na interface. F5 salva; Menu salva antes de sair. R recupera personagem morto na vila.

Veja docs/ROTEIRO-RPG-OFFLINE.md e docs/RELATORIO-FINAL-TASK-037_076.md. Coop experimental possui pacote/roteiro separados. A arena historica permanece acessivel no menu e pelos artefatos anteriores.
